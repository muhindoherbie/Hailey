
## What's new in 3.0

### Hailey on Android is now a standalone app

The Android app no longer opens a Hailey server through ngrok or another tunnel. Everything runs on the phone:

- **Hailey's own server runs inside the app.** It is the same code as on a PC, with SQLite (WebAssembly, with full-text search) and your files kept in the app's private storage.
- **Free AI with your own key.** On first start, choose **Groq** or **Google Gemini** (both free), **OpenRouter** free models, Claude, or a model on your own PC (Ollama). Hailey calls it directly; the key stays on the phone. A Groq key also turns Telegram voice notes into text.
- **Reminders ring while Hailey is closed** (Android alarms), and come back after a restart.
- **The phone's own voice:** speech recognition for dictation, Ramble and voice mode, and its own voices for reading replies aloud.
- **Share menu, widget and downloads** work natively. Replies and files can be shared to WhatsApp or any app.
- **Your data stays on the phone.** *Settings → Privacy* can export it or erase everything.

The new app installs as an update over the earlier one (same package and signing key). It keeps its own data, separate from a Hailey server on your PC. If you want one Hailey across several devices, keep using the server in a browser.

### Smaller changes

- The Android check in CI now builds the bundle, opens the APK on an emulator, and waits for Hailey's in-app server to report it has started.
- The Anthropic adapter works inside the app, and the server accepts a session held by the app itself in place of a cookie.
