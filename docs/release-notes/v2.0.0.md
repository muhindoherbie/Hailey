### What's new in Hailey 2.0

**Smarter, more private AI**
- **Local-only mode:** your conversations never leave your machine. If your local model (Ollama) is down, Hailey tells you instead of quietly switching to a cloud model.
- **Automatic model choice** (optional): everyday and sensitive messages go to your local model; documents, analysis and long chats go to the cloud model. Hover a reply's model name to see why.
- **Connection test** for each AI provider, plus a **monthly** token limit next to the daily one.

**Planning**
- **Task dependencies**, with warnings for overloaded days and for tasks due before what they depend on. The assistant can check your workload too.
- A fuller **evening review**: what you finished, what is still open, project progress and tomorrow's priorities. Routines now show whether their last run worked.

**Works offline**
- Add tasks, complete them, and edit tasks, notes and projects without a connection. Changes sync automatically when you are back online, each exactly once. If something was changed elsewhere in the meantime, Hailey asks which version to keep.

**Software projects**
- Ask Hailey about a GitHub repository's open issues, pull requests, latest release and recent commits. This is read-only: Hailey never writes to GitHub.

**Look and feel**
- New optional **Midnight** colour palette (navy, emerald and cyan) in Settings → Appearance. The classic look stays the default.

**Safety**
- Each action waiting for your approval is now locked to its exact details and expires after 7 days.
- Fixed: older reminders could disappear from the reminders list, and some date-based suggestions used the wrong clock.

**Upgrading:** your data is kept. The database update only adds new tables and columns, and it runs automatically on first start. If you need to go back to 1.0, reinstall it; your data stays readable.
