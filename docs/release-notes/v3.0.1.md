
## What's fixed in 3.0.1

- **Google Gemini works for new accounts.** Google retired `gemini-2.5-flash` for new users. Hailey now uses `gemini-flash-latest`, Google's name for its current Flash model, so it keeps working as Google moves on.
- **A rejected model name is easy to fix.** When the AI service refuses the model, *Save and test* now lists the models your key can use; tap one to switch and test it.
